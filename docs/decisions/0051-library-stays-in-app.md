# 0051 · The library stays inside the app

Date: 6 Nov 2026 · Founder: "Will go with your recommendation."

The bundled reference data (IFCT 2017 foods, Bhagavad Gita, Daily Wisdom, exercises; about 1.9 MB in `assets/data/`)
stays in the app: instant, works offline, no server cost, and quick updates can still change it. Only the Library row
left the Profile page. Rule of thumb: small text libraries stay in the app; audio, video and anything large live on the
server (as Myra's voice files already do).
